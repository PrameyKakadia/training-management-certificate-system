# Automated Training Management & Certificate System

A Google Workspace automation solution that streamlines training administration by automating participant registration, assessment processing, certificate generation, and email distribution.

## Features

- Training Registration using Google Forms
- Quiz Assessment Management
- Automatic Score Processing
- PDF Certificate Generation
- Email Delivery Automation
- Google Drive Integration
- Training Record Management

## Technologies

- Google Apps Script
- Google Forms
- Google Sheets
- Google Docs
- Gmail API
- Google Drive API

## Workflow

Registration Form
→ Google Sheets
→ Quiz Submission
→ Score Evaluation
→ Certificate Generation
→ PDF Creation
→ Email Delivery
